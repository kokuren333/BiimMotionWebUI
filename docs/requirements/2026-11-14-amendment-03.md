# Amendment 03 — BiimMotion の UI は製品ファミリーの世界観に統一する

- 日付: 2026-11-14 01:44 JST
- 発信: オーナー（Ren）
- 原文: 「ちなみにUIはこれもcyberspriteや mankomixみたいに同一の世界観で使いまわせるUIは使い回す感じにしたいんだけど」

## 決定

BiimMotion の WebUI（第2波 T6/T7）は、CyberSprite／MankoMIX と同一の製品ファミリーテーマ **「Circuit White / Solder Mask」** を基調にし、使い回せる UI（デザイントークン、アイコン、共通部品）は3プロダクトで共有する。

- 正本は CyberSprite の `gui/src/theme/tokens.css`（`--cs-*`：board `#EEF6F8`、trace `#19C3E6`、ink `#0B2A3A`、agent `#7C5CFF` ほか）。MankoMIX は ADDENDUM3（2026-11-13）で同じテーマを採用済み。BiimMotion は3つ目の採用プロダクトになる。
- CyberSprite の 16×16 ピクセルアイコン（`gui/public/icons/`）は、意味が合うものを再利用する。BiimMotion 固有のアイコンは同じ11色パレット・同じ様式で新規に描く。
- 第2波の `docs/DESIGN.md` は独自パレットを定義せず、ファミリートークンを正本として参照し、BiimMotion 固有の差分だけを規定する。

## D12（Biim枠UI）との関係

- 要件書 D12 は WebUI の骨格を出力映像の Biim 枠レイアウト（biim-standard-v1）に寄せる決定だった。本 Amendment により、**アプリの外装（シェル、フォーム、ナビゲーション）はファミリーテーマに置き換える**。
- Biim 枠の見た目は **ステージ／プレビュー領域のモチーフ** として残す（映像の見え方そのものは出力仕様であり、UI シェルの配色とは別）。様式モード biim のプレビューが Biim 枠で表示されるのは自然な帰結であり、シェルが Circuit White であることと矛盾しない。
- 出力映像の仕様（biim-standard-v1、字幕帯域、QC 規則）は本 Amendment の対象外で、変更しない。

## 補足（2026-11-14 01:45、オーナー指示）

「pages版も今までのプロジェクト同様にUI用意する感じでね」— GitHub Pages 版も、CyberSprite 等の過去プロジェクトと同様に、ファミリーテーマの UI を備えた状態で公開する。公開②の成果物は Pages 用ビルド（`npm run build -- --base=/BiimMotionWebUI/`）そのものであり、その UI がファミリーテーマで完成していることが公開条件。CP-A2 のスクリーンショットは Pages 用ビルドに対して撮り、VERIFICATION.md に記録する。G4-β の検証には Pages 用ビルドの成功とスクリーンショット記録を含める。

## 第2波への含意

- T6／T7 の DIRECTION には本 Amendment を織り込む。T8b の表示名統一（BiimMotion）と合わせて、公開②の姿は「ファミリーテーマ＋BiimMotion ブランド」になる。
- ファミリートークンの実物は CyberSprite repo 側にあるため、第2波の実働はトークンの写しを BiimMotion 側に取り込む（値の正本は CyberSprite、写しの同期は手作業でよい。自動同期の仕組みは作らない）。

## 補足（2026-11-14 01:45、オーナー指示）— Pages 版もファミリーテーマ UI で公開する

原文：「pages版も今までのプロジェクト同様にUI用意する感じでね」

- 公開②の成果物は Pages 用ビルド（`npm run build -- --base=/BiimMotionWebUI/`）そのものであり、その UI がファミリーテーマ（Circuit White / Solder Mask）で完成していることが公開条件になる。Pages 版だけ旧 UI のまま、または素のまま公開される状態を作らない。
- CP-A2 のスクリーンショットは、Pages 用ビルド（base パス `/BiimMotionWebUI/` 付きの成果物）をローカル配信したものに対して撮り、`VERIFICATION.md` に記録する。
- G4-β の検証には、Pages 用ビルドの成功と、その CP-A2 スクリーンショット記録を含める。
